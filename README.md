# Luna graphics

Luna 用户态图形软件。连接 libdrm、Mesa、Weston 与 Qt，提供渲染、桌面合成和应用开发所需的软件包。

**分支**　`master` · 主线开发与集成。

## 仓库入口

- [scripts](scripts)　构建与维护工具
- [docs](docs)　开发文档
- [qt5](qt5)　Qt 应用工具包
- [mesa](mesa)　OpenGL 实现
- [libdrm](libdrm)　DRM 用户态接口
- [weston](weston)　Wayland 合成器
- [glmark2](glmark2)　图形基准程序
- [kmscube](kmscube)　KMS 渲染示例
- [RELEASE.md](RELEASE.md)　图形软件包发布说明
